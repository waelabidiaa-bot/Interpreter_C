# C Interpreter

still learning i hope i continue this project it needs organizing tbh but hey it works!

## What it does

- Tokenizes the input
- Parses arithmetic expressions
- Builds an AST
- Handles operator precedence and parentheses
- Evaluates expressions
- Detects basic syntax errors
- Frees allocated memory

## Supported operators

`+`, `-`, `*`, `/`



## How to run

Compile:

```
make
```

Run:

```bash
./bin/interpter_inC
```
